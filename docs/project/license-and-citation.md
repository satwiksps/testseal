See the [contribution guide](https://github.com/satwiksps/testseal/blob/main/CONTRIBUTING.md)

## Third-party software

The Python core has no runtime dependencies. The GitHub Action's generated
bundle includes third-party JavaScript packages. Their license texts are
committed in `packages/action/dist/licenses.txt` and shipped with the Action.

Development, documentation, and website dependencies retain their own licenses.

## Citation

Machine-readable citation metadata is available in
[`CITATION.cff`](https://github.com/satwiksps/testseal/blob/main/CITATION.cff).
GitHub renders this metadata through the repository's **Cite this repository**
control.

Use the current release version and repository URL when citing TestSeal in a
paper, report, benchmark, or dataset. If exact behavior matters, include the Git
commit because rule precision can improve between releases.
